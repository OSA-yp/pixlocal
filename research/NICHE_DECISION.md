# Niche Decision — сентябрь 2026

## Победитель

**Приватный онлайн-хаб для изображений в браузере** (бренд: **ПиксЛокал**).

| Поле | Решение |
|---|---|
| Главный интент | Сжать фото / изображение / картинку онлайн без загрузки на сервер |
| Клин в SERP | HEIC → JPG (более досягаемые позиции на старте) + long-tail compress |
| Killer-фича | Файлы не покидают устройство; пакет; ZIP; русский UI; без регистрации |
| Почему не PDF | Конкуренция iLovePDF/Smallpdf непробиваема для нового домена |
| Почему не «удалить фон» | Тяжёлый AI-MVP |
| Почему не счётчик/ИМТ | AI zero-click в 2026 |

## Скоринг (кратко)

1. Compress image (privacy) — **3.90**
2. HEIC→JPG — **3.80**
3. WebP convert — **3.65** (включаем как посадочные)

## MVP-функции

1. Сжатие JPEG/PNG/WebP (canvas / browser-image-compression), слайдер качества, целевой размер.
2. HEIC/HEIF → JPG (heic2any / libheif).
3. Конвертация PNG↔JPG↔WebP.
4. Пакет + скачать всё ZIP.
5. Явный блок «файлы не отправляются на сервер».
6. Юр. страницы, FAQ, микроразметка WebApplication/FAQPage.
7. Слоты рекламы (РСЯ/AdSense) — выключены до трафика.

## Unit-экономика (порядок)

При eCPM РСЯ ~50–150 ₽ и 50k визитов/мес → грубо 2.5–7.5k ₽; при 200k — пропорционально выше. Цель 6–12 мес: кластер long-tail + рост по HEIC/compress.
