# Этап 1. Seed и источники (сентябрь 2026)

## Методология

1. Seed-паттерны utility: `сжать`, `конвертер`, `генератор`, `онлайн`, `удалить фон`, форматы файлов.
2. Расширение через **Яндекс Suggest API** (`suggest.yandex.ru`) — 32 маркера → **319 уникальных фраз** ([seed_phrases.txt](seed_phrases.txt)).
3. Плотность кластеров по вхождениям фраз: [cluster_density.json](cluster_density.json).
4. SERP: DuckDuckGo HTML (RU) — [ddg_serp.json](ddg_serp.json); Яндекс/Google Trends/Bing частично заблокированы (captcha/429) из этой среды.
5. Wordstat (логин/API) в этой среде недоступен без аккаунта — частотность оценивается **прокси**: suggest-плотность + тип конкурентов в выдаче + известная структура рынка utility. Перед масштабированием рекламы цифры нужно сверить вручную в [Wordstat](https://wordstat.yandex.ru).

## Топ кластеров по плотности suggest-фраз

| Кластер | Фраз в пуле | Сигнал спроса |
|---|---:|---|
| compress_image | 30 | сильнейший (в т.ч. топ-подсказки «сжать» → пдф/фото/картинка) |
| char_count | 25 | высокий, но слабая AI-устойчивость |
| qr / png_jpg | 19 | высокий |
| webp | 13 | средний+, evergreen |
| remove_bg | 11 | высокий, тяжёлый MVP |
| compress_pdf / heic / password / translit / bmi | 9–10 | заметный |

## Ключевой рыночный вывод 2026

По обзорам конкурентов и SERP HEIC/WebP: **загрузка файлов на сервер** доминирует у гигантов (iLoveIMG, Convertio, TinyPNG), а пользовательский запрос 2026 — **приватность + пакет + без регистрации**. Это и есть щель для нового сайта.
